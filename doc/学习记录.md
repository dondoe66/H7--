### git 操作的顺序:


1. `git init` 初始化本地仓库
1. `git add .` 将所有文件加入暂存区
2. `git commit -m "first commit"` 完成第一次提交
3. 修改 `Core/Src/main.c`，将 `BLINK_TIMES` 从 `3U` 改为 `5U`
4. `git add Core/Src/main.c` 暂存修改的文件
5. `git commit -m "将闪烁次数调整为5"` 提交修改
6. `git checkout -b feature-blink` 创建并切换到新分支
7. 在 `feature-blink` 分支上修改亮灯次数并提交
8. `git checkout main` 切换回主分支
9. `git log --oneline`查看历史
10. `git diff main feature-blink`比较 main 分支和 feature-blink 分支之间的代码区别。
11. `git merge feature-blink` 将 feature 分支合并到 main
12. `git branch -d feature-blink` 删除已合并的分支
13. `git remote add origin <仓库地址>` 关联远程仓库
14. `git push -u origin main` 推送到 GitHub
15. 编写学习记录后再次 add、commit、push

### 部分命令作用
|命令|作用|什么时候用|
|--|--|--|
|git branch|列出所有本地分支|查看当前处于主支还是分支|
|git switch +分支|切换到分支|切换分支|
|git push origin +分支|上传分支|上传分支|
|git merge a main|合并a和main|合并分支|
|git branch -d +分支|删除分支|删除本地分支|
|git push origin --delete +分支|删除远程分支|删除远程分支|

1. 将新组件添加进Group，命名为user ，再将user_beep.c添加进这个Group;
2. 在 Options for Target -> C/C++ -> Include Paths 里加上 ..\user\inc；
3. 打开 Core/Src/main.c，把 `// #include user_beep.h `这行改成` #include "user_beep.h"`；
4. 编译，下载，复位后观察现象
5. 依次移除hardware/src/buzzer.c、led.c ，hardware/inc，编译后记下报错
6. 修改main.c 里的DELAY_MS,从250U改成500U,重新编译下载，观察速度变化，并单独提交：
```
git add Core/Src/main.c
git commit -m "change delay to 500"
```
