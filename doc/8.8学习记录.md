### 作业3 LED 按编号闪烁不同次数：LED1 闪 1 次、LED2 闪 2 次……

1. 在led.c文件中添加led_blink_func()函数

```
// LED按编号闪烁函数：每颗 LED 闪烁次数等于 LED 编号，亮/灭延时为 delay_ms 毫秒
void led_blink_func(uint32_t delay_ms,uint8_t led_count) //参数包括闪烁的时长和灯的总数
{
    for (uint8_t i = 1; i <= led_count; i++)     //从第一个灯开始，挨个执行
    {
        uint8_t led_num = i ;                 //定义当前待点的灯
        uint8_t blink_count = led_num;      //定义点灯次数
        while(blink_count-- > 0)         //通过while判断，具体控制灯的点亮和熄灭
        {
            led_on(led_num);
            HAL_Delay(delay_ms);
            led_off(led_num);
            HAL_Delay(delay_ms);
        }

    }
}
```

2. 在led.h文件中添加led_blink_func()函数声明
   ```
   void led_blink_func(uint32_t delay_ms,uint8_t led_count);//和函数定义保持一致
   ```

3. 函数调用
   
   <br/>
   ```
   while (1)
     {
       led_blink_func( delay_ms, led_count);  //写下函数名(实参)
     }
   ```

### 作业4：流水灯报警系统

1. 把 `blink_led() `和 `beep()` 从 `main.c` 移到 `user/src、user/inc` 目录下的`alarm_sys_func.c`里封装，`alarm_sys_func()` 也放在同一个新文件里；
2. 定义模式变量`uint8_t mode = 1U; /* 0:待机 1:运行流水灯 2:报警：流水灯+蜂鸣器 */`
3. 用switch写模式切换

```
void alarm_sys_func(void)
{ 
  switch (mode)
  {
  case 0U:
    break;
  case 1U:
    current_led = 1U;    

    /* while 循环：条件成立就反复执行 {} 里的代码 */
    while (current_led <= led_count)
    {
      blink_led(current_led, blink_times, delay_ms);
      current_led++; /* 等价于 current_led = current_led + 1 */
    }
    break;
  case 2U:
    current_led = 1U;  
/* while 循环：条件成立就反复执行 {} 里的代码 */
    while (current_led <= led_count)
    {
      blink_led(current_led, blink_times, delay_ms);
      current_led++; /* 等价于 current_led = current_led + 1 */

    }
      beep(BEEP_MS);
    /* if / else 判断：让延时每次变快一点，到 100 后重新回到初始值 */
    if (delay_ms > 100U)
    {
      delay_ms -= 20U; 
    }
    else
    {
      delay_ms = DELAY_MS;
    }
    break;
    default:
    break;
  }
}
```

4. 在`alarm_sys_func.h`中写函数声明

```
#include "stdint.h"
void blink_led(uint8_t led_num, uint16_t times, uint32_t delay_ms);
void beep(uint32_t beep_ms);
void alarm_sys_func(void);
```

5. 在main.c文件里加入函数声明
   ```
   #include "alarm_sys_func.h"
   ```

6. 调用函数
   ```
     while (1)
     {
       alarm_sys_func();
     }
   ```
