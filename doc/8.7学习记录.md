使用markdown记录自己配置 Keil 工程的完整步骤、遇到的报错和解决办法。可以不交截图，但要把关键配置和报错写清楚。

### 编译烧录步骤
1. 安装STM32H7器件支持包;
   最初直接从Keil软件上的`Pack Installer`安装，但联网安装占用内存过大，安装失败；
   最终从keil官网下载安装 `STM32H7xx_DFP`
2. 在Options for Target 的 Debug 中调整 Use:选择ST-Link Debuugger
3. 编译，确定没有error
4. 连接ST-Link,下载，复位后观察 LED 闪烁情况和蜂鸣器发声情况

### 配置工程
1. 将新组件添加进Group，命名为user ，再将user_beep.c添加进这个Group;
2. 在 Options for Target -> C/C++ -> Include Paths 里加上 ..\user\inc；
3. 打开 Core/Src/main.c，把 `// #include user_beep.h `这行改成` #include "user_beep.h"`；
4. 编译，下载，复位后观察现象
5. 依次移除hardware/src/buzzer.c、led.c ，hardware/inc，编译后记下报错

1. 编译：
- 预处理：处理 `#include`、`#define` 宏替换、条件编译；
- 编译：对 C 源码进行词法、语法、语义分析，生成 ARM 汇编或目标文件 `.o`；
- 汇编：启动文件 `startup_stm32h723xx.s `等汇编代码也被汇编成目标文件；
- 链接：把多个 `.o` 文件和库按地址分配链接在一起，生成可执行映像 .axf 和烧录文件 `.hex`；
2. 下载：通过 ST-Link 等调试器把 `.hex` 写入芯片 Flash。
